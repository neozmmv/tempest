# backend

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

```bash
bun db:migrate
bun db:generate
bun db:push
bun db:studio # ssh -L 4983:localhost:4983 host@ip
```

This project was created using `bun init` in bun v1.4.0. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
